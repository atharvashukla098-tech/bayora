01 // Attack Interception

The attack never touches the target.

Adversarial prompts are generated by the red harness, but every byte crosses the policy broker first. Injection patterns are detected before release; canaries are stripped from every response.

Live event: SC-01 — direct prompt injection, DETECTED at the broker.

02 // Tamper-Evident Ledger

Tamper with the past.
The chain remembers.

Every decision is appended to a hash-chained ledger. Each event seals the hash of the one before it. Edit a single byte anywhere, and every block after it breaks.

Checkpoints are signed with Ed25519. Even an attacker who recomputes every later hash — a chain that reads perfectly consistent — is rejected, because the signed checkpoint sealed the real head.
