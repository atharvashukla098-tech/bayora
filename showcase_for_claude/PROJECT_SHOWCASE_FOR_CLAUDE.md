# BAYORA — High-Assurance Zero-Trust AI Red-Teaming & Security Sandbox

## Overview for Claude
Bayora is an enterprise zero-trust security platform and red-teaming sandbox for frontier AI model deployments. It proves deterministic containment, zero-tamper auditability, and real-time adversarial evaluation with cryptographic rigor.

---

## 1. Anti-"Vibe-Coded" Design System
Unlike standard AI hackathon projects that rely on generic templates, purple glows, and Lucide icons, Bayora was built using an **Industrial High-Assurance Design System**:
- **Affordance Syntax**: Monospace bracket notation (`[►]`, `[RUN]`, `[TERM]`, `[PASS]`, `[SEAL]`, `[ISOLATION]`) instead of generic rounded icons.
- **Color Discipline**: Strict monochromatic obsidian/slate palette with precise contextual accents (Ed25519 cyan, EROFS containment amber, cryptographic emerald).
- **Typography**: Swiss high-contrast editorial hierarchy — bold black display headlines on crisp white, transitioning via scroll descent runway into obsidian deep space.
- **Zero Tropes**: 0 em dashes, 0 emojis, 0 fake testimonials, 0 bento boxes, 0 Lucide icons, 0 soft-blurred cards.

## 2. Real-Time WebGL & Shader Engineering
1. **Iridescent Typography Engine (`IridescentTypographyCanvas.tsx`)**:
   - Custom WebGL fragment shader with authentic thin-film chromatic dispersion and Fresnel reflectance.
   - Diagonal refresh-activated prismatic glance sheen sweeping across monumental background typography (`VERIFY EVERY PROMPT.`, `CONTAIN AT THE ROOT.`, `ENFORCE ZERO TRUST.`, `PROVE ZERO TAMPER.`).
   - Pre-warmed GPU driver pipeline, compile-time rotation matrices, 0-CPU-upload idle state, clocked at 120 FPS.

2. **Liquid Glass Observatory (`LiquidGlassCanvas.tsx`)**:
   - Procedural domain-warped obsidian fluid shader with subtle chromatic edge sheen and specular surface crests.
   - Anchored instantly behind continuous three-tier marquee tracks (`RED HARNESS`, `CANARY SCRUB`, `TARGET MODEL`, `KERNEL CONTAINMENT`).

3. **Cinematic 3D Cosmos & Scenarios (`CinematicCanvas.tsx`, `ScenarioScene.tsx`)**:
   - Interactive Three.js worlds: Canary Knot, Neural Gateway, and Memory Vault with real-time mouse parallax and reactive simulation modes.

## 3. Real Backend & Cryptographic Pipeline
- **FastAPI Engine (`http://127.0.0.1:8000`)**:
  - Live cryptographic block height counter.
  - SHA-256 / Ed25519 immutable audit ledger with verifiable event seals.
  - Linux Docker EROFS (Read-Only Filesystem) `Errno 30` kernel-enforced containment boundary.
  - Live interactive attack replay console with prompt injection containment and canary exfiltration blocking.
